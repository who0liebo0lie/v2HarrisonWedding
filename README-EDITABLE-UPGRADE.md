# Editable page upgrade

This folder replaces the five image-only pages with real HTML text and layout:

- adventure.html
- bingo.html
- cococay.html
- pickleball.html
- wedding-day.html
- css/editable-pages.css

## Install

Copy these files into the root of the existing `v2HarrisonWedding` repository. Preserve the `css` folder structure and choose Replace when prompted.

The pages still load the existing `css/site.css`, so the current shared header, navigation, fonts, and branding remain in place. The new `css/editable-pages.css` controls the editable page content.

## Editing

Open any HTML file in a text editor. Visible copy is written directly between HTML tags such as `<h2>`, `<p>`, and `<li>`. Times, dates, labels, and links can all be changed without recreating a PNG.

## Notes

- Existing site images and JavaScript are not included because they were not part of the uploaded file set.
- CocoCay weather wording is intentionally general and should be replaced with your preferred approved figures before launch.
- Bingo leaderboard and Pickleball team list are visual placeholders until connected to live data.
