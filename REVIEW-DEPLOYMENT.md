# Publish this review build with GitHub Desktop

1. Open GitHub Desktop and clone `v2HarrisonWedding`.
2. In File Explorer, open the cloned repository folder.
3. Delete the old repository contents, but keep the hidden `.git` folder.
4. Copy **everything inside this folder** into the cloned repository folder.
5. In GitHub Desktop, enter the summary `Replace preview with production review build`.
6. Click **Commit to main**, then **Push origin**.
7. Wait 1–3 minutes and open `https://who0liebo0lie.github.io/v2HarrisonWedding/`.
8. Hard-refresh with `Ctrl + Shift + R`.

The RSVP and questions forms intentionally remain in preview mode until the Apps Script URL is added in `js/config.js`. Booking prices and contact details remain `TBD`.
