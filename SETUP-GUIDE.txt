1. Unzip this package.
2. Open the extracted folder and copy everything inside it.
3. In GitHub Desktop: Repository > Show in Explorer (or Finder on Mac).
4. Paste into your repository folder and choose Replace files.
5. Commit summary: e.g. "Rebuild with corrected adventure itinerary and interactive pages".
6. Push origin.
7. Wait 1-2 minutes and press Ctrl+Shift+R (or Cmd+Shift+R) on the live site to force-refresh.

For how the Bingo and Pickleball pages get populated with real guest data
before the cruise, see BINGO-SETUP.md and PICKLEBALL-SETUP.md in this folder.

Every page is plain HTML/CSS/JS — open any .html file in a text editor to
make changes, and refresh your browser to preview.
